**115 网盘转存助手**会定时扫描指定的 Telegram 公开频道，识别其中的 115 分享链接，并自动转存到你的 115 网盘目录。它也可以识别磁力和 ED2K 链接，将其提交到 115 离线下载。

插件不需要 Telegram Bot 参与频道读取。Bot Token 只用于发送转存结果通知，是可选配置。

## 工作流程

```text
Telegram 公开频道
        ↓
提取文字、按钮和超链接
        ↓
可信域名与链接类型检查
        ↓
115 分享转存 / 115 离线下载
        ↓
保存记录、去重、统计和通知
```

## 主要功能

- 定时监控多个 Telegram **公开频道**，每行配置一个频道用户名。
- 识别消息正文中的 115 分享链接。
- 识别“点击跳转”“直达链接”“立即查看”“一键转存”等文字背后的真实链接。
- 支持 `115.com`、`115cdn.com` 和 `anxia.com` 分享地址，并统一转换为可处理的 115 链接。
- 保留并使用分享链接中的提取码。
- 可选识别 `magnet:` 磁力链接和 `ed2k://` 链接，提交到 115 离线下载。
- 支持 MoviePilot 订阅集成，只转存订阅中仍然缺失的资源。
- 使用 SQLite 保存处理记录，避免重复转存；也可选择重新处理。
- 可通过 Telegram Bot 向指定账号发送成功、失败和本轮汇总通知。
- 自动复用 MoviePilot 的网络代理访问 Telegram 页面和 Bot API。
- 插件详情页显示运行状态、今日统计和最近处理记录。

## 安全跳转策略

插件不会像浏览器一样随意点击页面中的按钮。

| 链接类型 | 处理方式 |
| --- | --- |
| `115.com`、`115cdn.com`、`anxia.com` | 识别并转存 |
| Telegram 官方域名中的可信包装参数 | 只解析参数，不打开跳转页面 |
| `magnet:`、`ed2k://` | 开启离线下载后提交到 115 |
| 广告域名、陌生短链、未知跳转页 | 不访问、不执行 |
| JavaScript 跳转 | 不执行 |

Telegram 包装链接只读取 `url`、`target`、`redirect`、`redirect_url` 和 `link` 参数。这样既能处理常见的“点击跳转”“直达链接”，又能降低误入广告网站的风险。

## 当前支持范围

| 场景 | 支持情况 |
| --- | --- |
| Telegram 公开频道 | ✅ 支持 |
| 正文中的直接 115 分享链接 | ✅ 支持 |
| 按钮或文字背后的可信 115 链接 | ✅ 支持 |
| Telegram 官方包装的可信链接 | ✅ 支持 |
| 磁力链接和 ED2K 链接 | ✅ 可选 |
| MoviePilot 订阅缺集过滤 | ✅ 可选 |
| Telegram 私有频道 | ❌ 暂不支持 |
| 广告、陌生短链和未知跳转页 | ❌ 主动拒绝 |
| 影巢页面自动登录、解锁和转存 | ❌ 暂未接入 |

> 影巢相关功能需要官方 OpenAPI/OAuth 授权。目前插件不会模拟登录，也不会绕过网站权限。

## 安装

### 1. 添加插件仓库

进入 MoviePilot V2 的插件市场设置，添加下面的自定义插件仓库：

```text
https://github.com/xhui999w/my-mp-plugins-v2
```

### 2. 刷新插件市场

刷新后搜索 **115 网盘转存助手**，确认显示的版本为 `1.3.1` 或更高版本。

### 3. 安装插件

点击“安装到本地”。安装成功后，在已安装插件中打开 **115 网盘转存助手**。

如果市场提示安装成功，但已安装列表中没有插件：

1. 先刷新浏览器页面。
2. 再重启 MoviePilot。
3. 回到插件市场重新安装。
4. 在 MoviePilot 日志中搜索 `Tg115Transfer` 或 `115转存助手`。

## 新手配置步骤

### 第一步：填写公开频道

只填写频道用户名，不要填写完整网址，也不要加 `@`。

例如频道地址是：

```text
https://t.me/xhui999w
```

配置中填写：

```text
xhui999w
```

多个频道一行一个。

### 第二步：填写 115 Cookie

在浏览器中登录你自己的 115 账号，取得完整 Cookie 后粘贴到 **115 Cookie（必填）**。

Cookie 相当于账号登录凭证：

- 不要发到聊天群、Issue 或日志截图中。
- 不要提交到 GitHub。
- Cookie 失效后，需要重新获取并保存。

### 第三步：填写保存目录 ID

打开 115 网页版并进入要保存资源的目录，从浏览器地址栏中找到 `cid` 参数，将其数值填写到 **保存目录ID**。

填写 `0` 表示保存到根目录。

### 第四步：选择需要的功能

- 普通 115 分享转存：不需要开启额外开关。
- 磁力和 ED2K：开启 **启用115离线下载（磁力 / ED2K）**。
- 仅处理 MoviePilot 缺失资源：订阅集成模式选择 **仅转存订阅缺失资源**。
- 需要 Telegram 通知：填写 Bot Token 和管理员用户 ID，并开启通知。

### 第五步：保存并测试

1. 开启 **启用插件**。
2. 首次测试时开启 **立即运行一次**。
3. 点击保存。
4. 等待约 10～30 秒。
5. 打开插件详情页查看统计和最近记录。
6. 在 MoviePilot 日志中搜索 `115转存助手`。

正常日志示例：

```text
【115转存助手】频道 @example 扫描完成，新链接: 2 条
【115转存助手】发现115分享: https://115.com/s/...
【115转存助手】本轮监控完成 | 发现 2 条 | 成功 2 条 | 失败 0 条
```

## 配置说明

| 配置项 | 是否必填 | 说明 |
| --- | --- | --- |
| 启用插件 | 是 | 开启定时监控 |
| 立即运行一次 | 否 | 保存后执行一次扫描，会自动关闭 |
| 检查间隔 | 是 | 默认 10 分钟，建议 5～30 分钟 |
| 单次最大处理数量 | 是 | 默认 50，限制一次扫描的处理量 |
| 公开频道列表 | 是 | 每行一个频道用户名 |
| Bot Token | 否 | 只用于发送 Telegram 通知 |
| 管理员用户ID | 否 | 接收通知的 Telegram 数字 ID |
| 115 Cookie | 是 | 115 登录凭证，请妥善保管 |
| 保存目录ID | 是 | `0` 为根目录，其他值为目录 `cid` |
| 重复处理方式 | 是 | `skip` 跳过记录，`reprocess` 重新处理 |
| 115 离线下载 | 否 | 处理磁力和 ED2K 链接 |
| 订阅集成模式 | 否 | 可只转存 MoviePilot 订阅缺失资源 |
| 转存结果通知 | 否 | 需要同时配置 Bot Token 和用户 ID |

## 常见问题

### 保存后没有任何反应

依次检查：

1. **启用插件**是否已打开。
2. 频道是否为公开频道，用户名是否填写正确。
3. MoviePilot 容器能否访问 `https://t.me/s/频道用户名`。
4. 115 Cookie 是否仍然有效。
5. 是否开启了“立即运行一次”，或者等待了完整的检查间隔。
6. 日志中搜索 `115转存助手`，不要只搜索插件的市场名称。

### 扫描到了链接，但转存失败

- `405 METHOD NOT ALLOWED`：请升级到 `1.2.6` 或更高版本。
- Cookie 无效：重新取得 Cookie 并保存。
- 分享已失效或提取码错误：请先在浏览器中手动验证分享。
- 保存目录无效：重新检查目录 `cid`。
- 旧失败记录被去重：临时把重复处理方式改为 `reprocess` 后再测试。

### 磁力或 ED2K 没有反应

确认已开启 **启用115离线下载（磁力 / ED2K）**。插件提交成功只代表任务进入 115 离线列表，不代表文件已经下载完成。

### “点击跳转”为什么没有被处理

插件只处理最终目标为可信 115 域名，或 Telegram 官方包装参数中包含可信目标的链接。陌生域名、广告页和短链会被主动忽略。

### 私有频道能不能监控

当前不能。插件读取的是 Telegram 的公开频道网页 `t.me/s/...`，没有登录 Telegram 用户账号。
